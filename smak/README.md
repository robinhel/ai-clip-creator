# Smakfiler

En smakfil beskriver vad som gör klipp i en viss stil bra, till exempel `gta.md` för GTA-klipp.
Texten är på engelska och går in i Claudes val av klipp, sist i focus, efter körningens focus och minnet.

Kampanjens profil väljer smakfil med fältet `style`, till exempel `style: gta` för `smak/gta.md`.
Utan `style` används ingen smakfil.

Robin kan ändra texten när han vill. Håll den kort, högst cirka 150 ord, med korta punkter.
Rubriker som börjar med `#` skickas inte till Claude.
